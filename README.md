### 🚀 项目

#### [mc-motd](https://github.com/must-be-the-Airconditi/mc-motd) — Minecraft 服务器 MOTD 查看器

[![test](https://github.com/must-be-the-Airconditi/mc-motd/actions/workflows/cli.yml/badge.svg)](https://github.com/must-be-the-Airconditi/mc-motd/actions/workflows/cli.yml)
![License](https://img.shields.io/badge/License-MIT-4a9e5c?style=flat-square)

命令行 + 本地网页版 + 桌面 GUI 三种形态，直连 Server List Ping 协议，零运行时依赖：

- `motd <地址>` 终端里看彩色 MOTD 卡片
- `motd --web` 起本地网页版
- Java Swing 桌面版，macOS / Windows / Linux / BSD 通用
- 支持 SRV 解析、§ 颜色码、十六进制色、代理，CLI / 网页版中英双语

→ [仓库](https://github.com/must-be-the-Airconditi/mc-motd) · [下载](https://github.com/must-be-the-Airconditi/mc-motd/releases)

### 🚀 Projects

#### [mc-motd](https://github.com/must-be-the-Airconditi/mc-motd) — a Minecraft server MOTD viewer

[![test](https://github.com/must-be-the-Airconditi/mc-motd/actions/workflows/cli.yml/badge.svg)](https://github.com/must-be-the-Airconditi/mc-motd/actions/workflows/cli.yml)
![License](https://img.shields.io/badge/License-MIT-4a9e5c?style=flat-square)

CLI + local web UI + desktop GUI, talking the Server List Ping protocol directly, with zero runtime dependencies:

- `motd <address>` — a colored MOTD card in your terminal
- `motd --web` — a local web UI
- Java Swing desktop app for macOS / Windows / Linux / BSD
- SRV resolution, § color codes, hex colors, proxies; bilingual CLI / web UI

→ [Repository](https://github.com/must-be-the-Airconditi/mc-motd) · [Releases](https://github.com/must-be-the-Airconditi/mc-motd/releases)
